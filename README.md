# رحب — منصة السفر والحجوزات

صفحة هبوط لمنصة "رحب": طيران، تأشيرات، فنادق، سيارات، سائق خاص، وباقات شهر العسل، مع أداة تقدير سعر فوري ترسل طلب العميل جاهزًا عبر واتساب.

## التشغيل

ملف واحد بدون أي بناء أو تثبيت: افتح `index.html` في المتصفح.

## النشر على GitHub Pages

Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / `root` ← Save.
يصير الموقع متاح على `https://<username>.github.io/<repo>/`.

## الإعدادات

داخل `index.html` في أول السكربت:

```js
const CONFIG = { whatsapp: '966500000000' };
```

غيّر الرقم لرقم واتساب الاستقبال بالصيغة الدولية بدون `+`.

أسعار التقدير موجودة في كائن `PRICES` بنفس السكربت.

## قبل الإطلاق

- استبدل رقم الواتساب التجريبي برقمك.
- الأرقام في قسم الثقة (+5,000 رحلة… إلخ) وآراء العملاء والمدن في الفوتر **نصوص تجريبية** — استبدلها ببيانات حقيقية أو احذفها.
- راجع الأسعار في `PRICES` لتطابق أسعارك.
